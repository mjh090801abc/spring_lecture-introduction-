spring boot란 java 프로그램을 보다 쉽고 빠르게 만들 수 있는 도구이므로
스프링 부트는 미리 준비된 설정과 기능을 제공하여 자바 웹 개발을 더 빠르고 효율적으로 진행이 가능

이 강의에서는 JDK와 IntelliJ IDEA를 설치하고 spring boot를 활용하여서 개발

스프링 부트의 프로그램 시작 : src/main/java
html과 같은 정적 파일 : src/main/resources/static

[localhost:8080](http://localhost:8080)/… 여기서 localhost는 내 컴퓨터 주소를 뜻하고 8080은 포트번호를 뜻함
